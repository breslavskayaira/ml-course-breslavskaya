## 📈 Распределение целевой переменной (`SalePrice`)

| Статистика | Значение |
|------------|----------|
| Среднее | $180 921 |
| Медиана | $163 000 |
| Минимум | $34 900 |
| Максимум | $755 000 |
| Асимметрия (skew) | **1.88** (правое смещение) |
| Эксцесс | **6.51** |

**Вывод:** распределение сильно скошено вправо, поэтому в ноутбуке применяется логарифмирование целевой переменной (`np.log1p`) для приближения к нормальному распределению. После преобразования асимметрия снижается до ~0.12.

## ⚠️ Пропуски в данных

Всего 19 столбцов содержат пропуски. Основные из них:

| Столбец | Доля пропусков | Стратегия обработки |
|---------|----------------|---------------------|
| `PoolQC` | 99.5% | Заполнение значением `"None"` (нет бассейна) |
| `MiscFeature` | 96.3% | `"None"` |
| `Alley` | 93.8% | `"None"` |
| `Fence` | 80.7% | `"None"` |
| `FireplaceQu` | 47.3% | `"None"` (нет камина) |
| `LotFrontage` | 17.7% | Медиана по району (`Neighborhood`) |
| `GarageType`, `GarageFinish`, `GarageQual`, `GarageCond` | ~5.5% | `"None"` (нет гаража) |
| `BsmtQual`, `BsmtCond`, `BsmtExposure`, `BsmtFinType1`, `BsmtFinType2` | ~2.5–3% | `"None"` (нет подвала) |
| `MasVnrType`, `MasVnrArea` | ~0.5–0.8% | `"None"` / 0 |
| `Electrical` | 0.07% | Мода |
| Другие числовые | < 1% | Медиана |

**Обоснование:** пропуски в столбцах, описывающих объекты (бассейн, гараж, подвал и т.п.), означают отсутствие этого объекта, поэтому заполняются `"None"` или `0`. Для `LotFrontage` используется медиана по району, так как размер участка зависит от местоположения.
